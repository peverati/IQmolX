# iqmolx-engine-lennard-jones

A small, complete example of an IQMolX engine plugin: Lennard-Jones clusters of noble gases
(He, Ne, Ar, Kr, Xe) with Lorentz-Berthelot mixing. It is real code that the tests of
`iqmolx-engines` install and run; the developer guide `PLUGINS.md` is written around it.

    pip install ./python/examples/iqmolx-engine-lennard-jones     # into the environment of the helper
    iqmolx-engines --describe                                     # the "lj" engine is listed

The parameters are rounded textbook values for illustration, not for research.
